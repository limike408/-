# C 题（微电网电功率优化调度）结果说明

> 配套程序：`code\`（config / data / lp / scenarios / results / main_q1~q4 / q2_lambda_sweep /
> export_plot_data / season_split）；R 绘图：`scripts_r\`

## 一、问题概述与统一口径

微网含 **光伏 + 储能 + 电网购电**，需以 10 分钟为时段（每天 144 时段）制定购电计划，
在满足负荷、储能上下限与充放电功率约束下最小化购电费用。

**统一变量单位**：能量量纲 kWh/时段（功率 kW × 时段长 1/6 h = kWh）。
**储能参数**（附录1）：容量 1200–12000 kWh（运行界 1200–10800），
充/放电功率上限 5000 kW，充放电效率 η=0.9，初始储电 6000 kWh。
**电价机制**：紧急购电 = 交易时刻电价×5；计划高于调整（少购）部分按 50% 违约价、
调整高于计划（多购）部分按 150% 超额价。

| 选项 | 含义 |
|---|---|
| P | 计划购电（0:00 制定，承诺付费） |
| A | 滚动调整后最终购电 |
| G | 光伏出力 |
| D | 负荷 |
| Q | 紧急购电 |
| c / f | 充电 / 放电量 |
| E | 储电量 |

**信息因果原则**：每个决策时点只使用该时点之前可得的数据——Q2 只允许 0:00 一次决策；
Q3 在 0/6/12/18 四次决策，负荷一律用历史预报（前 K_L=15 天逐槽均值 + 成对残差情景），
光伏用附件 3 对应时点官方预报为基准。禁止把当日实际负荷/光伏当作决策时已知。

**风险口径（v2）**：Q2 官方结果启用 CVaR 风险权衡（λ=λ*，由全年权衡曲线数据驱动选定，
见下）；Q3/Q4-3 **不引入** CVaR 权重——四次预报更新逐次吸收不确定性，滚动再计划本身即
风险对冲手段，再叠加 λ 会与违约/超额惩罚重复计价。

## 三、第二问：两阶段随机规划 + CVaR（官方口径 v3）

**口径**：预报式两阶段随机规划。每天 0:00 用截至前一日的历史数据：
1) 点预报 = 负荷/光伏各前 K_L=15 / K_P=7 天逐槽均值（K 由全年交叉验证数据驱动选出）；
2) 情景 = 整日成对残差 bootstrap（S=30，负荷与光伏同一天成对抽取，seed=2026+日序）；
3) 计划 P = 两阶段随机规划（式 obj2），**风险权重 λ=λ\* 由全年权衡曲线选定**；
4) 结算 = 固定 P 对当日实际负荷/光伏重调度，紧急购电 Q 按 5 倍价，E_end 结转次日。
冷启动：2025-01-01 用附件 1 典型日剖面。全年链自 1.1 起（1 月仅预热），输出 2.1–12.31。

**λ\* 选取（数据驱动）**：在 λ∈{0,0.5,1,1.5,2,3,5} 上对全年逐一遍历（`q2_lambda_sweep.csv`）：

| λ | 计划购电费 | 紧急购电费 | 合计 |
|---|---|---|---|
| 0.0 | 15,133,792.26 | 1,074,587.33 | 16,208,379.58 |
| **0.5** | **15,726,290.43** | **478,538.57** | **16,204,829.00** ← λ* |
| 1.0 | 15,732,680.77 | 475,065.44 | 16,207,746.21 |
| 1.5 | 15,799,301.14 | 420,391.58 | 16,219,692.71 |
| 2.0/3.0/5.0 | 15,799,301.14 | 420,374.16 | 16,219,675.30（饱和） |

取 **λ\* = 0.5**（拐点：紧急费较 λ=0 下降 55.5%、合计微降 0.02%）：以几乎零成本把紧急购电
风险减半。

**官方结果 `result2.xlsx`（λ\* 口径）**：

- 计划购电费 **15,726,290.43 元**
- 紧急购电费 **478,538.57 元**（148,180 kWh）
- 合计 **16,204,829.00 元**

四指定日（`report/q2_specdays_Q.csv`）：

| 日期 | 计划购电费 | 紧急购电量(kWh) | 紧急购电费 |
|---|---|---|---|
| 2025-03-20 | 43,652.3 | 29.3 | 197.4 |
| 2025-06-21 | 49,345.5 | 0 | 0 |
| 2025-09-23 | 40,734.3 | 1,666.5 | 5,526.6 |
| 2025-12-21 | 60,328.7 | 148.5 | 501.5 |

**关键结论**：λ 增大时计划费↑、紧急费↓；λ*=0.5 处紧急费腰斩而合计持平，体现"以计划费换
可靠性"的风险权衡。（图 `q2_lambda_tradeoff.png`、`A5_pareto.png`、`q2_cvar_tradeoff.png`）

## 四、第三问：因果滚动随机 MPC（官方口径 v2）

**口径**：
1) 0:00 计划：负荷历史残差情景 + 光伏附件3 0:00 预报残差情景 → 两阶段随机规划（λ=0）得 P；
2) 6/12/18 调整：调整时点储电初值 = 对已执行段"固定承诺购电 + 实际光伏/负荷（未来段用该
   时点点预报）"因果重放的真实 SOC；以附件3 该时点预报为基准的成对残差情景做
   **情景鲁棒调整**（式 adjust：min Σ[p·min(P,A)+0.5p·u+1.5p·w] + E[5p·Q^s]，
   违约/超额量由 A+u−w=P 精确绑定）；
3) 日终结算：固定最终 A 对当日实际重调度电池，紧急购电 Q 按 5 倍价（与 Q2 结算同口径）；
4) 费用 = p·min(P,A) + 0.5p·(P−A)⁺ + 1.5p·(A−P)⁺ + 5p·Q。

**结果文件 `result3.xlsx`**（计划/调整/紧急/充放电量 四张表，2.1–12.31）：

- 计划+调整电网费 **19,170,972.19 元**（其中超额惩罚 3,827,013.21 元、违约退款 78,667.51 元）
- 紧急购电费 **149,188.01 元**
- 合计 **19,320,160.21 元**
- 仅 0:00 基准（不调整，同情景同种子）全年合计 **16,232,288.50 元**

**多时刻预报是否值得**（表3 四日对比，见 `q3_rolling_comparison.csv`）：

| 日期 | 仅0:00(不调整) | 0/6/12/18 滚动 |
|---|---|---|
| 2025-03-20 | 43,593.3 | 50,858.4 |
| 2025-06-21 | 45,374.4 | 59,059.0 |
| 2025-09-23 | 44,112.5 | 53,944.7 |
| 2025-12-21 | 61,419.6 | 77,713.2 |

**关键结论（诚实呈现）**：滚动调整把全年紧急购电费几乎清零（149,188 元），但调整购电为
对冲情景尾部缺电风险系统性多购，超额部分按 1.5 倍价结算，全年超额惩罚约 382.7 万元，高于
其节省的紧急购电费（约 66 万元）——在题目 50%/150% 不对称结算规则下，"多时刻预报"的经济
价值有限，工程上建议"预报误差小的日子靠计划+紧急兜底、预报显著上修时再启用调整"的阈值策略。
（`q3_rolling_comparison.csv` / `figures\q3_forecast_time.png`）

## 五、第四问：波动电价重算 Q2 / Q3

用附件4 全年波动电价替换附件1 固定电价，重跑第二问（λ* 两阶段随机）/第三问（因果滚动
随机 MPC）统一口径。

| 指标 | 固定电价(附件1) | 波动电价(附件4) |
|---|---|---|
| Q2 计划购电费 | 15,726,290.43 | 15,802,243.35 |
| Q2 紧急购电费 | 478,538.57 | 568,531.52 |
| Q2 合计 | 16,204,829.00 | **16,370,774.87**（result4-2，+1.0%） |
| Q3 电网费 | 19,170,972.19 | 19,254,978.23 |
| Q3 紧急购电费 | 149,188.01 | 184,810.38 |
| Q3 合计 | 19,320,160.21 | **19,439,788.61**（result4-3，+0.6%） |

**季节费用拆分**（日均，万元/日，见 `season_cost_split.csv`）：

| 季节 | Q2固定 | Q2波动 | Q3固定 | Q3波动 | Q3上浮 |
|---|---|---|---|---|---|
| 春 | 4.03 | 3.77 | 4.88 | 4.55 | −6.7% |
| 夏 | 5.20 | 5.53 | 5.98 | 6.27 | +4.9% |
| 秋 | 4.67 | 4.56 | 5.73 | 5.58 | −2.6% |
| 冬 | 6.11 | 6.59 | 7.18 | 7.80 | **+8.6%** |

**结果文件**：`result4-2.xlsx`（计划购电量 / 紧急购电量 / 充放电量）、
`result4-3.xlsx`（计划 / 调整 / 紧急 / 充放电量）。

**关键结论**：波动电价使 Q2/Q3 费用分别上浮约 **+1.0% / +0.6%**（预报式口径已含保险性
多购，敏感度低于完美信息口径的直观估计），且电价波动风险存在显著季节差异——**冬季最大
（+8.6%）**、夏季次之（+4.9%）、春秋反而略降，凸显电价波动对购电决策的影响及分季购电
策略的必要性。图 `q4_price.png`、`A10_season_cost.png`。
