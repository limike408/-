## 一、问题概述与统一口径

微网含 **光伏 + 储能 + 电网购电**，需以 10 分钟为时段（每天 144 时段）制定购电计划，
在满足负荷、储能上下限与充放电功率约束下最小化购电费用。

**统一变量单位**：能量量纲 kWh/时段（功率 kW × 时段长 1/6 h = kWh）。
**储能参数**（附录1）：容量 1200–12000 kWh（运行界 1200–10800），
充/放电功率上限 5000 kW，充放电效率 η=0.9，初始储电 6000 kWh。
**电价机制**：紧急购电 = 交易时刻电价×5；计划高于调整（少购）部分按 50% 违约价、
调整高于计划（多购）部分按 150% 超额价。

| 选项 | 含义 |
|---|---|
| P | 计划购电（0:00 制定，承诺付费） |
| A | 滚动调整后最终购电 |
| G | 光伏出力 |
| D | 负荷 |
| Q | 紧急购电 |
| c / f | 充电 / 放电量 |
| E | 储电量 |

## 三、第二问：两阶段随机规划 + CVaR

**A. 官方结果 `result2.xlsx`（2.1–12.31 全量）**
口径（18.0 起）：每天 0:00 依据截至前一日的历史数据（信息因果，不含未来）——负荷/光伏点
预报取各自前 K_L=15 / K_P=7 天逐槽均值（全年交叉验证选出），S=30 个整日成对残差 bootstrap
情景（seed=2026+日序），以两阶段随机规划求解计划购电 P，再按当日实际负荷/光伏结算得紧急购电
Q（5 倍价）。全年 λ 扫描采用数据驱动选定风险权重 **λ\*=0.5**。

- 计划总购电费 **15 726 290.43 元**
- 紧急购电费 **478 538.57 元**（148 179.5 kWh）
- 合计 **16 204 829.00 元**

λ 从 0 增至 0.5：计划费仅上浮 3.9%，紧急购电费削减 55.5%，全年总费用基本持平（−0.02%），
即以极小计划费增量换取缺电风险显式成本大幅削减。（`q2_lambda_year_scan.csv`）

**B. 方法层（论文用，不进结果文件）：两阶段随机 + CVaR**
以历史情景（bootstrap 30 个情景）做两阶段随机规划，目标 = 计划购电费 + 平均紧急购电费
+ λ·CVaR₀.₉（情景总成本）。在表3 指定日期做风险厌恶敏感性：

| 日期 | λ=0 合计 | λ=0.5 合计 | λ=1 合计 | 要点 |
|---|---|---|---|---|
| 2025-03-20 | 42582 | 43850 | 43912 | 低风险日轻微上行 |
| 2025-09-23 | 47976 | 46261 | 46261 | 紧急 2563→1666 kWh |
| 2025-12-21 | 62424 | 60830 | 60795 | 紧急 1102→122 kWh |

**关键结论**：增大 λ（风险厌恶程度）以轻微的计划费上涨换取紧急购电与总费用显著下降，
体现 CVaR 风险约束的有效性。（`q2_two_stage_comparison.csv` / `figures\q2_cvar_tradeoff.png`）

## 四、第三问：滚动随机 MPC + 调整惩罚（18.0 因果口径）

**口径**：0:00 以附件1 电价 + 光伏点预报（负荷取前 K 天均值，冷启动用附件1）制定计划购电 **P**；
6/12/18 时点以最新光伏预报生成 S=30 情景、做**情景鲁棒**滚动再计划得调整购电 **A**
（`solve_adjust_scen`），并以本期实际负荷/光伏**回放实际 SOC**、按"去后见之明"逐段结算（违约
50%/超额 150%）；日终对当日实际重调度得紧急购电。
费用 = p·min(P,A) + 0.5p·(P−A)⁺ + 1.5p·(A−P)⁺ + 5p·Q。

**结果文件 `result3.xlsx`**（计划购电量 / 调整购电量 / 紧急购电量 / 充放电量 四张表，2.1–12.31）

- 计划+调整电网费 **22 460 575.77 元**
- 紧急购电费 **75 922.06 元**
- 合计 **22 536 497.83 元**

**多时刻预报是否值得**（表3 四日对比，18.0 因果口径）：

| 日期 | 仅0:00(不调整) | 0/6/12/18 滚动 | 滚动紧急购电费 |
|---|---|---|---|
| 2025-03-20 | 37674 | 60429 | 0 |
| 2025-06-21 | 34650 | 66011 | 0 |
| 2025-09-23 | 43518 | 62940 | 0 |
| 2025-12-21 | 57197 | 86547 | 2446 |

**关键结论（诚实呈现）**：去除后见之明后，滚动再计划虽把多数日期紧急购电削减为 0（表3 中四个
指定日期仅 12-21 有紧急购电 428 kWh），但违约/超额调整惩罚使滚动总费用普遍高于仅 0:00 计划。
原因：(1) 再计划会触发违约/超额惩罚；(2) 紧急购电主要由**光伏预报误差的总量**决定，而非购电
时段分配——购电只决定"何时买"，不改变"缺多少"。该发现是问题4 引入波动电价与鲁棒/随机方法的
动机。（`q3_rolling_comparison.csv` / `figures\q3_forecast_time.png`）

## 六、紧急情况统计与供电可靠性论证（19.0 新增）

**定义**：以决策日 0:00 信息集为准（信息因果），日净需求 $n_d=\sum_t(D_t-G_t)$，0:00 点预报
$\hat n_d$ 由负荷前 K_L=15 日逐时段均值与附件 3 光伏 0:00 预报求得；日净需求预报偏差
$\varepsilon_d=(n_d-\hat n_d)/\hat n_d$，$\varepsilon_d>0$ 表示实际净需求被低估（缺电风险方向）。
**紧急波动日** = 低估超过 20%。

**全年统计（`emergency_analysis.csv`，365 天）**：

| 指标 | 数值 |
|---|---|
| 低估 ≥20%（紧急波动日） | **156 天（42.7%）** |
| 低估 ≥30% | 63 天（17.3%） |
| 低估 ≥10% / ≥15%（阈值敏感性） | 235 天（64.4%）/ 200 天（54.8%） |
| 实际触发紧急购电 | 166 天 |
| 严重缺电日（低估≥20% 且触发紧急购电） | 109 天 |
| 单日紧急购电 ≥50 kWh | 100 天 |
| 全年紧急购电合计 | 148 180 kWh |

**季节分布**：春 48 天（52%）、夏 47 天（51%）、秋 37 天（41%）、冬 24 天（27%）；
冬季虽紧急波动日占比最低，但叠加最低光伏与最高电价，购电费用冲击最大。

**结论**：净需求低估 ≥20% 的日期占比超四成，缺电风险是高频、季节聚集的现实威胁，
支撑论文"供电可靠性为主、经济性为辅"的优化目标定位。

`figures_adv\emergency_season.png`（季节柱状图）
脚本：`code\emergency_analysis.py`
