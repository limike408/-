## 三、口径变化详情（重要，论文正文已按此重写）

### 1. Q2：λ\*=0.5 风险权衡（用户拍板）
- 在 λ∈{0,0.5,1,1.5,2,3,5} 上全年逐一遍历（`code/q2_lambda_sweep.py`）→
  `report/q2_lambda_sweep.csv`。λ\*=0.5 拐点：紧急费较 λ=0 **−55.5%**、合计微降 0.02%；
  λ≥1.5 后计划费饱和。
- 官方链：`main_q2.py` 的 `LAM_OFFICIAL=0.5`；digest `a7fbf8154fb0752c`（`report/q2_digest.txt`）。
- **Q3/Q4 不用 CVaR**（论文正文点明理由）：0/6/12/18 四次预报更新已逐次吸收不确定性，
  滚动再计划本身即风险对冲，再叠 λ 会与违约/超额惩罚重复计价。

### 2. Q3：因果滚动随机 MPC（`main_q3.py` 重写）
1. **负荷预报化**：负荷不再用当日实际值，改用前 K_L=15 天逐槽均值 + 成对残差情景（与 Q2 同口径）；
2. **光伏情景化**：以附件3 各时点官方预报为基准 + 历史"实际−同点时点预报"整日残差
   bootstrap（`scenarios.residual_scenarios_fc3`），S=30、seed=2026+日序；
3. **情景鲁棒调整**：新 `lp.solve_adjust_scen`——调整购电 A 对情景共用、电池 c/f 与情景内
   紧急购电 Q 按情景决策；违约/超额量由 **A+u−w=P 精确绑定**；目标
   min Σ[p·min(P,A)+0.5p·u+1.5p·w] + (1/S)Σ5p·Q^s；
4. **实际储电轨迹**：调整时点 SOC 初值 = 对已执行段"实际光伏/负荷 + 未来段点预报"因果重放
   （未来段置 0 会导致电池躺平、SOC 恒下限 1200、调整购电被迫超买——已踩坑修复）；
5. **结算口径**：固定最终 A，对当日实际光伏/负荷重调度电池（电池视为日内实时可控），
   紧急购电 Q 按 5 倍价吸收缺口（与 Q2 结算同口径）；跨日连续 + 1 月预热。

### 3. 修复的旧 bug（务必周知）
- **旧 `solve_adjust` 已删除**：其 LP 只约束 A+u≥P 且 u≤P，目标又把 u 推向 P →
  "调整购电 A 免费"的退化口径（论文 eq 与代码实际求解不一致）。
- 新实现一度把超出部分重复计价（pA + 1.5pw → 2.5 倍），已改为 min(P,A) 等价目标。
- 旧 Q3 负荷已知、SOC 用计划轨迹、结算用全天实际重优化（后见之明）三处均已修正。

### 4. Q4：统一内核换价格
- Q4-2 = Q2 口径（λ\*=0.5 两阶段随机）换附件4 价格；Q4-3 = 新 Q3 口径换价格。
- 结论从旧的"+4.8%/+5.1%"变为 **+1.0%/+0.6%**（预报式口径自带保险性多购，对电价敏感度低）。
