# 论文模块内容组织逻辑报告

> 对应论文：`_rep/paper/main.tex`
> 《基于三层滚动随机模型预测控制的微网购电与储能调控优化》（2026 年 C 题）
>
> 本报告目标：讲清楚"论文为什么这样组织、各模块负责什么、模块之间如何衔接"，让读者顺着一条主线把全文穿起来，理清文章脉络。

---

## 一、全文主线：一句话概括

**本文用"确定性线性规划为基准 → 两阶段随机规划刻画尾部风险 → 滚动模型预测控制衔接预报更新 → 波动电价统一重算"的递进建模链，在同一个能量守恒内核下，逐步逼近真实微网调度中的不确定性与信息结构。**

所有模块都服务于这一句话：
- "确定性 → 随机 → 滚动 → 波动"是**纵向主线**（问题一→四）；
- "统一能量守恒内核 + 计划—调整—紧急三层购电结构"是**横向骨架**（四问共用）；
- "结果校验 + 季节分型 + 综合对比"是**收尾证明**（结果可信、机理可解释、方法可推广）。

| §5 模型建立与求解 | Q1 / Q2 / Q3 / Q4 | 四问模型 + 结果逐层递进 | **核心主体** |

布局逻辑：**先给结论（摘要）→ 再铺背景与思路（§1–§2）→ 立边界与字典（§3–§4）→ 主体递进建模（§5）→ 检验与对比（§6）→ 评价与推广（§7）**。这是"总分—总"的经典竞赛论文骨架：摘要是"总"，§2 问题分析是"思路总览"，§5 是"分"（四问），§6–§7 再回到"总"（综合证明与评价）。

## 三、逐模块组织逻辑详解

### 模块 1：摘要 —— "三问三答 + 创新点"的结论预告

摘要按"问题一→二→三→四 各一段"组织，每段严格对齐"**情景 → 模型 → 关键数字 → 机理结论**"四件套：

1. **问题一**：确定性场景 → 线性规划 + 日循环约束 → 计划购电 59482.7 kWh / 购电费 35126.8 元。
2. **问题二**：不确定性场景 → 两阶段随机规划 + CVaR → 信息因果口径下全年合计 16,208,379.6 元；并给出 λ 敏感性结论（"保险"属性）。
3. **问题三**：多时刻预报 → 计划—调整 MPC → 全年合计 15,263,487.8 元；诚实指出"部分日期费用上升"。
4. **问题四**：波动电价 → 统一框架重算 → 上浮 4.8% / 5.1%，冬季风险最高。

最后一段点出**三大创新点**：三层滚动随机 MPC 统一框架、CVaR 帕累托权衡、季节分型分析（带 ANOVA 统计证据）。

> 组织逻辑：摘要不与正文争细节，只给"结论 + 证据 + 创新"，让评委 30 秒内知道本文做了什么、做得多好、新在哪。

### 模块 2：问题背景与重述（§1）—— "为什么做、做什么"

- **背景（§1.1）**：先用文献锚定研究价值（微网重要、光伏负荷随机、储能可搬移能量、电价波动），再**抽象出科学问题**：带时间耦合与时序不确定性的多时段决策问题。这一段的关键技巧是——不照抄题目，而是把题目"翻译"成方法论语言（不确定性刻画方式决定求解质量）。
- **重述（§1.2）**：简述四个子问题的数据与要求，为后面"递进建模路线"埋钩子。

> 组织逻辑：背景回答"这题在方法论上考什么"，重述回答"具体要做什么"，二者合起来为 §2 的"逐问选型"铺路。

### 模块 3：问题分析（§2）—— 解题思路的"总控室"，全文最见功力的一章

这一章是评委判断"作者是不是真懂题"的地方，组织上分三层：

1. **统一框架（§2.1）**：先立规则——10 分钟一时段、T=144、三类数据组织。**先统一、再分治**是全文方法论的地基。
2. **四问逐个分析（§2.1–§2.4）**：每题按"**问题特征 → 关键决策 → 选型依据**"三段式：
   - 问题一：全已知 → LP 保全局最优 → 给出经济性**理论下界**；
   - 问题二：实时波动 → 期望成本与尾部风险权衡 → **CVaR**（一致性、可线性化两大理由）；
   - 问题三：0/6/12/18 多时点预报 → 滚动优化—滚动实施 → **MPC**（压缩情景树、串行 LP），并诚实指出"贪婪近似最优"的代价；
   - 问题四：电价波动 → 目标系数替换 → 复用内核做**压力测试**。
   - 每题都讲"为什么选这个模型、别的为什么不行"，这是问题分析的灵魂。
3. **技术路线 + 数据探索（§2.5–§2.6）**：技术路线图（图 fig:route）把四问画成递进链条；数据探索用季节统计（表 tab:season、图 A1–A3）+ ANOVA（F=28.7）证明"季节规律显著"，为问题二的分季情景窗、问题四的季节解读提供**数据证据**。

> 组织逻辑：问题分析章是全文的"作战地图"——先统一框架，再逐问选型，最后用数据支撑后续建模决策。读懂了这一章，后面 §5 的每个模型都不会意外。

### 模块 4：模型假设（§3）与符号说明（§4）—— 边界与字典

- 假设明确列出"简化什么"（如外网无限容量、忽略网损等），既保护模型成立范围，又体现严谨。
- 符号说明统一全篇记号，避免 P/G/c/f/Q/R/E 各章含义漂移。

> 组织逻辑：工具性章节，不承载创新，但缺失会让全文可读性崩塌。放在建模前是标准动作。

### 模块 5：模型建立与求解（§5）—— 核心主体，四问递进

**§5 开头先立"公共骨架"（最关键的组织设计）**：先定义"计划购电 P / 调整购电 A / 紧急购电 Q"三层购电结构，再给出全篇共用的功率平衡（式 balance）、储能递推（式 soc）与边界（式 socbound）。之后每一问都**只在这个骨架上加层**：

| 问题 | 信息结构 | 新增决策层 | 目标函数 | 相对上一问的增量 |
|---|---|---|---|---|
| 一 | 完美信息 | P | min Σ pP | 基准：经济性下界 |
| 二 | 情景随机 | P + Q | min Σ pP + (1/S)Σ5pQ + λ·CVaR | 加紧急购电、加情景、加尾部风险 |
| 三 | 滚动更新 | P + A + Q | 计划/违约 50%/超额 150% 分段结算 | 加调整层、加惩罚规则 |
| 四 | 波动电价 | 沿用二/三 | 只换目标系数 p→p'(t) | 加价格冲击维度 |

每个子问题内部又统一按"**建立 → 结果 → 机理**"展开：
- 问题一：模型（式 obj1/cycle）→ 结果（表 tab:q1 + 图 q1/sankey）→ 机理（低充高放、谷段购电 = 经济性下界）；
- 问题二：模型（式 obj2/cvar + 非预期性澄清）→ **情景生成方法论**（信息因果、K 交叉验证 KL=15/KP=7、整日成对残差 bootstrap、冷启动）→ 结果 → CVaR 权衡（帕累托前沿）；
- 问题三：模型（滚动调整目标）→ 结果（表 tab:q3）→ 机理（预报误差总量主导紧急购电）；
- 问题四：模型 → 结果 → 季节差异解读。

> 组织逻辑：**"同骨架 + 逐层加码"**让四个问题在视觉和逻辑上都像"一个模型的四个版本"而不是四个孤立模型——这正是本文区别于"拼盘式"论文的核心竞争力。每个问题的"建立"节还都会回扣 §2 的选型理由，形成前后呼应。

### 模块 6：模型检验与分析（§6）—— 从"算出结果"到"结果可信、机理可解释"

§6 是全文的"证据链"，六个子节按"**自证 → 参数稳健 → 机理归因 → 横向对比**"排列：

1. **能量守恒校验（§6.1）**：三类硬性校验（功率平衡残差 < 1e-6、储能越限、口径闭合）——先自证数值可信；
2. **CVaR 参数稳健性（§6.2）**：λ∈{0,…,5} 敏感性，验证"计划费↑紧急费↓"的保险属性，证明模型不是凑数；
3. **季节显著性检验（§6.3）**：ANOVA + 两两比较，支撑"冬季风险最高"的判断；
4. **预报误差分布检验（§6.4）**：Q-Q 图证明误差近似正态右尾偏重，并归因"预报误差总量主导紧急购电"——直接解释问题三结果；
5. **双口径评估（§6.5）**：完美信息 vs 随机/滚动、固定价 vs 波动价，汇总表 tab:summary 呈现"信息越充分决策越优"的单调关系；
6. **模型性能综合对比（§6.6）**：五维度半定量评分 + 雷达图，并用 AHP–TOPSIS 给出可量化合成路径。

> 组织逻辑：六个子节构成"**数值可信 → 参数稳健 → 机理可解释 → 方法可迁移**"的递进证据链，把四问结果从"一堆数字"提升为"有理论支撑的结论"。

### 模块 7：模型评价与推广（§7）—— 立意拔高与自省

- **整体解读（§7.1）**：把全文抽象为"由确定到随机、由静态到滚动、由单点到全季"三位一体递进框架——这是对 §5 的**再总结**，告诉评委"我不是四个模型，我是一套体系"；
- **优点（§7.2）**：统一可复用、风险—经济权衡显式化、忠实赛题规则、结果可信可操作；
- **不足（§7.3）**：主动自曝四点局限（bootstrap 只用一阶矩、忽略弃光价值、忽略网损、线性惩罚）——**自省是加分项**，体现学术诚实，也为推广埋线；
- **推广（§7.4）**：能源侧/市场侧/预测侧三方向 + 评分体系可移植性，把单题解法升华为通用方法论。

### 模块 8：附录 A/B —— 可复现性工程闭环

- 附录 A：支撑材料文件列表；
- 附录 B：16 个源码文件逐一说明（config→data→lp→scenarios→四问入口→结果回填→图表工具），代码结构与论文模型一一对应，实现"读论文即可复现代码"。

> 组织逻辑：附录不是凑字数，而是把"工程实现"与"论文模型"对齐，支撑"结果可信"。

## 四、模块间的承接关系（"穿起来"的关键）

用一条"**提出问题 → 拆解问题 → 递进求解 → 统一证明 → 升华推广**"的链把所有模块串起来：

```
§1 背景与重述        立题：多时段不确定决策
   │  把题目翻译成方法论语言
   ▼
§2 问题分析          拆题：统一框架 + 四问逐个选型 + 数据探索
   │  先统一、再分治；技术路线图定调
   ▼
§3–§4 假设与符号      立边界、定字典
   ▼
§5 模型建立与求解     求解：同一骨架逐层加码（P→P+Q→P+A+Q→换价格）
   │  Q1 基准 → Q2 随机 → Q3 滚动 → Q4 冲击
   ▼
§6 模型检验与分析     证明：守恒校验 → 参数稳健 → 机理归因 → 综合对比
   │  回扣 Q2 的 CVaR、Q3 的误差归因、Q4 的季节差异
   ▼
§7 评价与推广         升华：三位一体框架 + 自省 + 可移植性
```

**三处最关键的"回扣"设计（写作上刻意为之的闭环）：**
1. **§2 选型理由 ↔ §5 模型**：问题二选 CVaR 的理由（一致性、可线性化）在 §5 建模时再次验证；问题三选 MPC 的"贪婪代价"在结果中诚实呈现。
2. **§2.6 季节探索 ↔ §6.3 显著性检验 ↔ §6.5 双口径**：数据探索发现季节规律 → 检验证明显著 → 双口径解读中落到"冬季上浮 12.1%"。
3. **§5 四问结果 ↔ §6.5 汇总表 ↔ §7.1 整体解读**：四问费用在 tab:summary 并排呈现"信息越充分决策越优"，再被 §7.1 抽象为递进框架——数据、图表、论述三层呼应。

## 五、写作技巧速览（对照检查用）

1. **摘要每段"情景→模型→数字→机理"四件套**：不写过程，只给结论与证据。
2. **问题分析每题"特征→决策→选型依据"三段式**：让评委提前看到"我知道为什么这么做"。
3. **§5 先立公共骨架再逐问加层**：四问统一在"计划—调整—紧急"与守恒内核下，突出体系感而非拼盘感。
4. **每问结果都落到"机理一句话"**：如"低充高放"、"以计划费换可靠性"、"预报误差总量主导紧急购电"——数字背后必有解释。
5. **检验章用"证据链"而非"罗列"**：自证（守恒）→ 稳健（λ）→ 机理（ANOVA/QQ）→ 对比（双口径/雷达）。
6. **不足与推广主动写**：自省提升学术形象，推广把"解题"升华为"方法论"。
7. **参考文献与文中引用一一对应**：英文 ≤2 篇（HiGHS 求解器、CVaR 原始文献），其余均为中文权威期刊/专著（GB/T 7714-2025），并在背景、模型、评分处标记引用位置。
