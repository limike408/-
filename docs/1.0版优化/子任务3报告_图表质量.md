## 四、可直接运行的绘图代码

完整脚本：`C题\code\chart_advanced.py`（一次运行生成全部 8 图，约 40s，已实测通过）。

关键片段（热力图 + 帕累托前沿，数据来自真实两阶段求解）：

```python
LAMS = [0, 0.2, 0.5, 1, 2, 5]; BETS = [0.80, 0.85, 0.90, 0.95, 0.99]
grid = np.zeros((len(LAMS), len(BETS))); plan_arr = np.zeros_like(grid); emerg_arr = np.zeros_like(grid)
for ai, lam in enumerate(LAMS):
    for bi, beta in enumerate(BETS):
        two = lp.solve_two_stage(fp, fc['scen_ld'], fc['scen_pv'], E0, lam=lam, beta=beta)
        settle = lp.solve_day_fixedP(fp, pv[i0], load[i0], E0, two['P'])
        plan_arr[ai,bi] = np.sum(fp*two['P']); emerg_arr[ai,bi] = np.sum(5*fp*settle['Q'])
        grid[ai,bi] = plan_arr[ai,bi] + emerg_arr[ai,bi]
```

生成的 λ-β 网格（2025-03-20，总费用，元）——直接进论文：

| λ \ β | 0.80 | 0.90 | 0.99 |
|---|---|---|---|
| 0 | 57133 | 57133 | 57133 |
| 0.5 | 54907 | 54225 | 54419 |
| 1 | 54349 | **53963** | 53618 |
| 2 | 53962 | **53618** | 53618 |
| 5 | 54011 | **53618** | 53618 |

**解读**：λ=0→5 总费下降 6.2%；β 在 0.8–0.99 变化仅 ±500 元（<1%），模型对 β 稳健、对 λ 敏感——这正是"计划费换可靠性"的量化证据。
